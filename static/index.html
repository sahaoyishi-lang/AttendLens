100% Open-Source & University Privacy Guarantee

AttendLens is engineered exclusively using permissible open-source software (MIT, Apache-2.0, BSD-3-Clause, PSF). Zero proprietary APIs, zero closed-source cloud OCR vision services, and zero subscription SDKs are used. All image processing, QR decoding, cell segmentation, and database commits occur strictly inside the university's local server boundaries. Only synthetic, anonymized student records are used.

End-to-End Paper-to-Digital Vision Architecture

Workflow from printed physical sheet to verified database commitment.

1

Smart Sheet Generation

ReportLab draws 4 solid black corner fiducials + metadata QR code + target boxes.

2

Fiducial Deskewing

OpenCV detects 4 corner squares, applies cv2.warpPerspective to 1200x1700 canonical grid.

3

QR Metadata Decode

QRCodeDetector extracts subject code, date, and session token automatically.

4

Hybrid OMR / OCR

Cell slicing, pixel density analysis in P/A boxes, signature stroke validation, and uncertainty scoring.

5

Split-Screen & Audit

Teacher reviews cell crops, 1-click overrides, and commits records with full AuditLog trail.
